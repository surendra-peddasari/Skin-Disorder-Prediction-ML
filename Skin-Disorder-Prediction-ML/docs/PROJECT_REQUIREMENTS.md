# Project Requirements — PRCP-1027 Skin Disorder

The project brief requires:

- Complete data analysis.
- A machine-learning predictive model for the skin-disease classes.
- Suggestions for earlier identification by doctors.
- Comparison of multiple models and a production recommendation.
- A report describing challenges and the techniques used to address them.
- All tasks to be completed in a single Jupyter notebook for final submission.

The dataset is described as having 34 attributes: 11 clinical attributes, 22 histopathological attributes, and age, with six target disease classes.
