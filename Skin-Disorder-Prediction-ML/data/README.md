# Dataset

The raw `dermatology.data` dataset is intentionally not committed to this repository.

The notebook attempts to load the file locally and, if it is not found, downloads it from the UCI Machine Learning Repository URL embedded in the notebook.

Expected local filename:

```text
dermatology.data
```

The project brief describes 366 patient records, 34 attributes, and six erythemato-squamous disease classes.

Do not commit private or sensitive patient information to this repository.
